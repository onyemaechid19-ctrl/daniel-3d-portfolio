# Daniel Portfolio

A React + Vite developer portfolio with a Three.js particle sculpture.

## Requirements
- Node.js 18 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```

## Before publishing
- Replace `your-email@example.com` in `src/App.jsx`.
- Replace the GitHub and LinkedIn placeholder URLs with your own profiles.
- Update project descriptions and skills to reflect your current work.

The particle sculpture is a procedural abstract head-like point cloud, not a photorealistic human scan.
